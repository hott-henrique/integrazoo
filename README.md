# Integrazoo

Desenvolvimento de aplicação desktop para auxiliar na escrituração zootécnica de pequenos produtores de bovino de corte. 

## Projeto Arquivado
Desenvolvido durante a faculdade, eu estava muito animado para o desenvolvimento, no entanto foi a minha primeira aplicação de interface realmente complexa. Admito que o código ficou muito desorganizado, principalmente a parte de persistência dos dados.
